# 🔐 Password Generator (Python GUI)

## 🚀 Overview

This project is a **Random Password Generator** built using Python with a graphical user interface (GUI).
It allows users to generate secure passwords based on selected criteria such as length and character types.

This project was developed as part of the **Oasis Infobyte Python Internship**.

---

## ✨ Features

* 🔢 Custom Password Length
* 🔤 Include Letters (A-Z, a-z)
* 🔢 Include Numbers (0-9)
* 🔣 Include Symbols (!@#$%^&*)
* 🔐 Strong Random Password Generation
* 📋 Copy to Clipboard Feature
* 🖥️ User-friendly GUI using Tkinter
* ⚠️ Input Validation & Error Handling

---

## 🛠️ Technologies Used

* Python
* Tkinter (GUI)
* Random & String Modules

## 🎯 Usage

1. Enter password length
2. Select character options:

   * Letters
   * Numbers
   * Symbols
3. Click **"Generate Password"**
4. Copy password using **"Copy" button**
